# Changelog

## 1.0.0

First release.

- Version entries: a target Minecraft version plus the mods to check against it, several entries
  per version allowed, reorderable, renameable.
- Checks run per entry in the background against Modrinth, with a grey progress bar while they
  run and a red-amber-green bar once they finish.
- Per mod: ready, prerelease, not yet, or unknown to Modrinth, plus the newest Minecraft version
  the mod still reaches. Sortable by availability, name or source.
- Modrinth search with autocomplete and icons for mods that are not installed.
- Runs on Minecraft 26.1 through 26.2.
