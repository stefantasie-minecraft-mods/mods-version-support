# Language Policy

**Chat with Stefantasie: German** (informal "du", elevated register).

**Everything else: English.** No exceptions.

That covers:

- Java source, package and class names, method and field names, local variables
- Comments and javadoc
- `fabric.mod.json`, `gradle.properties`, build scripts, JSON config keys
- Translation keys in `assets/<modid>/lang/` and the `en_us.json` source strings
- Log messages and exception messages
- README, planning documents, guideline files, ADRs
- Git branch names, commit messages, PR titles and bodies
- Test names and test data
- Screenshots' UI text where it comes from source strings

German belongs in exactly two places: the chat, and `de_de.json` as a translation of the
English source strings.
